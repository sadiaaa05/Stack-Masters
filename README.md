## 🌿 Contribution Workflow
To maintain clean history, our team follows this exact workflow:
1. `git switch -c feature/your-feature-name` (Create your feature branch)
2. Make changes and commit: `git commit -m "feat: added login authentication"`
3. Push changes: `git push origin feature/your-feature-name`
4. Open a **Pull Request (PR)** on GitHub for code review before merging to `main`.
